# Support

## Website and project support

For a defect, content correction, or general project question, open a focused GitHub issue. State the affected route, the expected visitor outcome, the observed behavior, and the browser or device context where relevant.

For collaboration or project inquiries, contact [TechTide AI](https://techtideai.io). Please do not include credentials, private customer information, or vulnerability details in public issues.

## Response expectations

This repository is maintained on a best-effort basis. Issue triage prioritizes broken public experiences, accessibility regressions, and security concerns. Contributions and support requests are governed by the standards in [CONTRIBUTING.md](./CONTRIBUTING.md) and [SECURITY.md](./SECURITY.md).
